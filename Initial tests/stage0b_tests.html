Stage 0b: closed browser, push, install

A. Survives being closed

Start the test, then close the browser (or let work focus mode close it). Reopen after a minute or more. The clock should show the true time left, not restart.

B. Push through ntfy (works with the browser closed)

1. Install the free ntfy app and subscribe to the topic below. 2. In Garmin Connect, allow notifications from ntfy. 3. In Android settings, set ntfy battery use to Unrestricted. Anyone who knows the topic name could send to it, so keep it to yourself.

Close the browser right after scheduling. Does the phone, then the watch, buzz at the right time?

C. Installed app (Firefox menu, Install or Add to Home screen)

After installing, open it from the home screen icon, start test A, then let work focus mode kick in or open the work profile. Does it get closed?
